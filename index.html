Space History Shorts Publisher

A personal tool for publishing my own educational space-history videos.

I make short educational videos about early NASA missions — Pioneer, Mercury, Ranger, TIROS and others — built entirely from public-domain archival material with narration checked against NASA sources.

This tool renders those videos, writes a caption for each one, and publishes them to my own social accounts on a fixed daily schedule. It runs on my own computer. It is not a product, not a service, and has no users other than me.

What it does

  • Renders a finished video file from a script and archival images
  • Generates a caption and hashtags for each platform
  • Publishes on a schedule to accounts I own and have authorised
  • Records whether each post succeeded, so failures can be retried

TikTok integration

The tool uses TikTok's Login Kit to authorise my own account, and the Content Posting API to publish one already-rendered video per day to that account. Before each post it queries the creator information endpoint so that the privacy options and interaction settings my account actually allows are respected rather than assumed.

It never posts to any account but mine, and it cannot be used by anyone else.

Content and sources

Imagery is public-domain material from NASA, NSSDCA, the U.S. Air Force and Wikimedia Commons, credited on screen in every video. This is an independent educational project and is not affiliated with, endorsed by, or sponsored by NASA or any government agency.
