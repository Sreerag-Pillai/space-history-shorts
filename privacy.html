Privacy Policy

Space History Shorts Publisher · last updated 26 July 2026

This is a personal tool operated by one person for the sole purpose of publishing their own videos to their own social media accounts. It has no other users, no sign-up, and collects no information from the public.

What this tool accesses

When the operator authorises their own TikTok account, TikTok issues an access token and a refresh token. Using those tokens, the tool can read:

  • Basic profile information for that account — the open ID, display name, username and avatar (via the user.info.basic scope)
  • The posting options the account permits — available privacy levels and whether comments, duet or stitch are disabled

It uses the video.publish scope to upload and publish video files that the operator has produced.

What is stored, and where

Tokens and the account's open ID are written to a local configuration file on the operator's own computer. Nothing is transmitted to, stored on, or processed by any third-party server. There is no hosted backend, no database, and no cloud storage. Profile information is read at the moment it is needed and is not retained.

What is never done

  • No data is sold, rented, shared, or disclosed to anyone
  • No analytics, tracking, advertising or profiling of any kind
  • No access to any account other than the operator's own
  • No collection of information about viewers, followers or commenters

Retention and deletion

Tokens are kept only while the tool is in use. Authorisation can be withdrawn at any time from TikTok's own settings, under Security and permissions → Manage app permissions, which immediately invalidates them. Deleting the local configuration file removes every stored credential. Because no data is held anywhere else, that is a complete deletion.

Children

The tool is not directed at children and collects no information from anyone, including children.
